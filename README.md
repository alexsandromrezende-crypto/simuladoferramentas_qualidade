# Simulado SAEP-2026.2 — Técnico em Administração

Aplicação estática em HTML, CSS e JavaScript, sem dependências externas.

## Publicar no GitHub e Vercel

1. Crie um repositório no GitHub e envie `index.html` para a raiz do repositório.
2. Entre no Vercel e escolha **Add New → Project**.
3. Importe o repositório do GitHub.
4. Como é um site estático, não configure build command nem output directory; deixe as configurações padrão ou selecione **Other** como framework.
5. Clique em **Deploy**.

O arquivo `index.html` na raiz será servido automaticamente.

## Recursos
- 40 questões, campos para nome e turma, correção e percentual de acertos.
- Relatório abre em uma nova janela para impressão ou salvamento como PDF.
- A questão 18 está configurada com alternativa A como gabarito.

## Observação sobre o bloqueio de cópia
As restrições de seleção e atalhos são apenas barreiras básicas do navegador. Como o gabarito e as questões são enviados ao navegador, não é possível impedir totalmente inspeção do código, capturas de tela ou consulta por outro dispositivo.
